# Markdown的使用

### 一、对Markdown的认识
    Markdown 是一种轻量标记语言，核心思路：用简单的标记符号给纯文本加上格式。它的源文件本质就是纯文本，不包含任何二进制样式信息。目前通用的事实标准是ommonMark规范；各大平台（GitHub、Typora、Obsidian、飞书等）会在此基础上追加自定义拓展语法，拓展语法不属于原生基础规范。

### 二、基本语法

### 1.1
| 语法 | 写法 | 效果 / 说明 |
| --- | --- | ---|      
| 一级标题 | `# 标题` | `#` 与文字之间**必须有一个空格** |
| 二级标题 | `## 标题` | 依此类推 `###`、`####`，最多到六级 |
| 无序列表 | `- 内容` | 也可用 `*` 或 `+`，项目内保持统一 |
| 有序列表 | `1. 内容` | 序号会自动接续 |
| 加粗 | `**文字**` | 强调关键结论，不宜整段加粗 |
| 斜体 | `*文字*` | 轻微强调 |
| 行内代码 | `` `code` `` | 变量名、命令、函数名、文件名 |
| 代码块 | 三个反引号包裹，可标注语言 | 多行代码、配置文件 |
| 链接 | `[显示文字](url)` | 显示文字在前，地址在括号里 |
| 分割线 | `***/---` | 单独一行，用于分隔大章节 |
| 引用 | `>/>>/>> 引用内容` | 常用于摘录题意、原文说明 |
